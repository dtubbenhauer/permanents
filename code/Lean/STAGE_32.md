# Stage 32 — The global square identity of Lemma 7E.1

For q ≥ 2 unit packets in any finite Gram dimension, subtract the sum of squared two-step paths over i < j from (q−2)M₁+4M₂. The difference is the sum of the incident-edge exterior squares and the uncrossing squares for four distinct labels. Both terms carry the exact orientation multiplicities. The result holds with repeated packet values and also when q = 2.
