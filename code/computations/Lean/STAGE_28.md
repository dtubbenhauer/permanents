# Stage 28 — Last-cap resolution on either edge of a crossing pairing

Apply the supported trace-cup projection to one edge of an actual two-edge halfweb. The other edge may carry any finite linear map. This gives both orientations of both crossing pairings; the remainder is a sum of energies of explicit perpendicular halves over the spectator indices. The proofs apply to arbitrary jointly supported inputs.

- `BlockPermanents.BalancedLastJoint.joint_entry`
- `BlockPermanents.BalancedLastJoint.terminal_energy`
- `BlockPermanents.BalancedLastJoint.joint_split`
- `BlockPermanents.BalancedLastJoint.first_split`
- `BlockPermanents.BalancedLastJoint.second_split`

- `BlockPermanents.BalancedLastJoint.secondSquares_nonneg`
