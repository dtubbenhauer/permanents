# Stage 31 — The two-step path with fixed endpoints

At fixed endpoints the diagonal contribution splits into a retained edge and an incident-edge remainder. For unit packets this remainder is the edge weight times the squared exterior product. Distinct middle labels give the squared difference of the opposite-edge amplitudes. Both the directed and symmetrized local identities hold on any finite set of middle labels. The squared differences have factor one half when both orders of the middle labels are summed.

The declarations checked individually in this stage are

- `BlockPermanents.TwoStepSquares.local_matrix`

- `BlockPermanents.TwoStepSquares.local_squares`
