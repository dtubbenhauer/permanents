# Stage 33 — Two-step paths with a disjoint spectator matching

For any fixed spectator matching, the relabelled two-step path and its explicit reflected-square remainder add to |U| times the first matching extension and |U|(|U|−1) times the second. U is the set of available middle labels. This includes the empty and singleton cases. The remainder retains the spectator product on the incident and opposite-edge squares.

The declarations checked individually in this stage are

- `BlockPermanents.TwoStepSpectator.count_extensions`
- `BlockPermanents.TwoStepSpectator.path_squares`
- `BlockPermanents.TwoStepSpectator.remainder_nonneg`
